# Agentic Evaluation Tasks

This category contains annotation task designs for evaluating LLM agents: coding agents, web and GUI agents, multi-agent systems, process reward modeling, and trajectory review.

> Run these designs in [Potato](https://www.potatoannotator.com). See the [agent evaluation documentation](https://www.potatoannotator.com/docs) for trace displays, process-reward annotation, and multi-agent schemes.
